# FNP-Sales-Performance-Dashboard
An Excel-based dashboard to analyze sales, revenue, customer spending, and product performance for FNP (Ferns N Petals).


## 🔎 About the Project

This project focuses on analyzing FNP sales data using an interactive Excel dashboard. It gives a simple view of orders, revenue, products, customers, and sales patterns.

## 💻 Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning & Analysis

## 📂 Files Used

The analysis is based on three datasets:

- `customers.csv`
- `orders.csv`
- `products.csv`

## 💡 What I Analyzed

- Revenue generated from different occasions
- Performance of different product categories
- Monthly revenue trends
- Top products based on sales
- Number of orders from different cities
- Revenue based on order time
- Average customer spending

## 🎯 Project Purpose

The purpose of this project is to turn raw sales data into useful information that is easy to understand. The analysis can help identify sales trends and better-performing products, categories, and locations.
